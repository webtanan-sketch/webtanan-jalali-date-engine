# رابط کاربری صنعتی Webtanan Jalali Date Engine

## v0.3.1

در این نسخه پایه رابط کاربری تقویم اضافه شد.

ویژگی‌ها:

- طراحی RTL فارسی
- ساختار مینیمال مدیریتی
- آماده برای موبایل و دسکتاپ
- هدر ماه و سال
- ساختار روزهای هفته
- نمایش رویداد روی روزها

قابل استفاده در:

- Laravel Blade
- React
- Vue
- HTML
- Electron

نسخه‌های آینده:

- انتخاب تاریخ واقعی
- انتخاب بازه
- انتخاب زمان
- تعطیلات ایران
- وضعیت کاری روزها

# راهنمای نصب Webtanan Jalali Date Engine

## Laravel / PHP

نصب با Composer:

```bash
composer require webtanan/jalali-date-engine
```

قابل استفاده در:

- Laravel
- Symfony
- PHP خام
- سایر Framework های PHP

---

## JavaScript

نصب با NPM:

```bash
npm install webtanan-jalali-date-engine
```

قابل استفاده در:

- React
- Vue
- Angular
- Vite
- Electron
- HTML ساده

# استفاده در Laravel

## نصب

```bash
composer require webtanan/jalali-date-engine
```

## استفاده

```php
use Webtanan\JalaliDateEngine\JalaliDate;

echo JalaliDate::format(1405, 6, 11);
```

## امکانات آینده

- Service Provider لاراول
- Facade اختصاصی
- Blade Component
- Validation Rule
- API Resource Support

این پکیج برای Laravel، Symfony و PHP Native طراحی می‌شود.

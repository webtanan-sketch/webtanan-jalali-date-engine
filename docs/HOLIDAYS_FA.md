# دیتاست تعطیلات رسمی ایران

از نسخه `v0.10.0` دیتاست کامل تعطیلات رسمی سال‌های ۱۴۰۴ و ۱۴۰۵ داخل Webtanan Jalali Date Engine قرار دارد.

## سال‌های موجود در هسته

```text
۱۴۰۴
۱۴۰۵
```

هر سال دارای ۲۶ روز تعطیل رسمی مناسبتی است.

منبع ثبت‌شده در Dataset:

- تقویم رسمی کشور
- مناسبت‌ها مصوب شورای فرهنگ عمومی کشور
- استخراج و تنظیم شورای مرکز تقویم مؤسسه ژئوفیزیک دانشگاه تهران

هر Dataset علاوه بر تعطیلات شامل metadata زیر است:

```ts
{
  year,
  source: {
    title,
    url,
    verifiedAt
  }
}
```

## استفاده ساده

```ts
import { IranHolidayProvider, HolidayEngine } from 'webtanan-jalali-date-engine';

const holidays = new HolidayEngine();
const provider = new IranHolidayProvider();

holidays.load(provider, 1405);

holidays.isHoliday('1405/01/25');
```

برای سال‌های ۱۴۰۴ و ۱۴۰۵، Provider به‌صورت خودکار دیتاست کامل داخلی را استفاده می‌کند.

برای سالی که هنوز Dataset رسمی آن داخل پکیج نیست، Provider فقط تعطیلات ثابت شمسی را به‌عنوان fallback برمی‌گرداند و تعطیلات قمری/متحرک را حدس نمی‌زند.

## سیاست به‌روزرسانی سالانه

برای هر سال جدید:

1. تقویم رسمی همان سال دریافت می‌شود.
2. روزهای تعطیل رسمی استخراج و بازبینی می‌شوند.
3. Dataset جدید با سال و منبع مستقل ساخته می‌شود.
4. `verifiedAt` ثبت می‌شود.
5. تست تعداد روزها، تاریخ‌های مرزی و اعتبار همه تاریخ‌ها اجرا می‌شود.
6. هسته تبدیل تاریخ تغییر نمی‌کند مگر اینکه تست تقویم رسمی ایرادی در آن نشان دهد.

این روش باعث می‌شود تعطیلی‌های موقت، استانی یا تصمیم‌های اضطراری دولت به اشتباه وارد تقویم رسمی دائمی نشوند.

## تعطیلی‌های اختصاصی کارخانه یا شرکت

تعطیلی‌های سازمانی باید جدا از Dataset رسمی ثبت شوند:

```ts
holidayEngine.add({
  date: '1405/06/11',
  title: 'تعطیلی کارخانه',
  type: 'company',
  source: 'company'
});
```

## سال کبیسه

سال کبیسه بخشی از `JalaliConverter` است و به Dataset تعطیلات وابسته نیست.

نمونه‌های تست‌شده:

```text
۱۴۰۳ کبیسه است → اسفند ۳۰ روز
۱۴۰۴ عادی است → اسفند ۲۹ روز
۱۴۰۵ عادی است → اسفند ۲۹ روز
```

بنابراین:

```ts
JalaliConverter.isValid({ year: 1403, month: 12, day: 30 }); // true
JalaliConverter.isValid({ year: 1404, month: 12, day: 30 }); // false
```

## منبع داده

برای ۱۴۰۴ و ۱۴۰۵ منبع اصلی ثبت‌شده، تقویم رسمی مرکز تقویم مؤسسه ژئوفیزیک دانشگاه تهران است.

# راهنمای استفاده در فریم ورک ها

## Laravel

نصب:

```bash
composer require webtanan/jalali-date-engine
```

قابل توسعه برای:
- Service Provider
- Facade
- Blade Component
- Validation Rule

## React / Vue / Angular

نصب:

```bash
npm install webtanan-jalali-date-engine
```

## HTML ساده

استفاده مستقیم از فایل JavaScript و CSS.

## Electron

قابل استفاده برای نرم افزارهای دسکتاپ ویندوز.
